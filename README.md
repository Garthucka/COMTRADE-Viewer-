# COMTRADE Viewer V9 — Техническая документация

## Общее описание

**COMTRADE Viewer** — десктопное GUI-приложение для просмотра, анализа и экспорта данных в формате COMTRADE (IEEE Std C37.111). Приложение написано на Python с использованием PyQt6 в качестве фреймворка для интерфейса и Matplotlib для построения графиков.

Основные возможности:
- Загрузка COMTRADE-файлов (.cfg + .dat) с автоматическим исправлением несоответствий формата и поддержкой множества кодировок
- Построение аналоговых и дискретных каналов в двух режимах: наложение и параллельный просмотр
- Два независимых измерительных курсора с привязкой к реальным сэмплам
- Расчёт параметров участка между курсорами (ΔT, ΔY, средняя скорость)
- Экспорт результатов измерений в CSV
- Отображение и сохранение протокола из .info-файла (испытание выключателя и DRM)

## Глобальные справочники

Словари-константы уровня модуля используются для расшифровки числовых кодов в .info-файлах испытания выключателя:

| Имя | Назначение |
|---|---|
| `_INFO_TRIGGER_SOURCE` | Источник триггера: 0 — нет, 1 — внешний, 81 — авто |
| `_INFO_TRIGGER_FRONT` | Фронт триггера: 1 — нарастающий, 2 — спадающий |
| `_INFO_SENSOR_TYPE` | Тип датчика: 0 — ход (линейный), 1 — угловой |
| `_INFO_CYCLE_TYPE` | Тип цикла: 0 — О, 1 — В, 2 — О-В-О |
| `_INFO_OPERATION_TYPE` | Тип операции (дублирует CYCLE_TYPE, для блока операций) |

## Функции модульного уровня

### `convert_info_json_to_report(data, source_path, speed_unit) → str`

Принимает разобранный Python-словарь из .info JSON-файла испытания выключателя и возвращает полный текстовый протокол в виде строки.

**Аргументы:**
- `data: dict` — содержимое JSON (.info файл)
- `source_path: str` — путь к исходному файлу (для заголовка протокола)
- `speed_unit: str` — единица скорости (`"м/с"` для линейного датчика, `"°/с"` для углового)

**Внутренняя логика:**
1. Извлекает секции `meas_sett` (настройки измерения) и `calc_data` (результаты)
2. Преобразует Unix-timestamp в строку даты UTC
3. Формирует список строк `lines` через локальную функцию `sep()` (горизонтальные разделители)
4. Строит блок «НАСТРОЙКИ ИЗМЕРЕНИЯ» — расшифровывает триггер, фронт, тип датчика и цикла, времена операций через глобальные справочники
5. Определяет единицу хода: `°` при `sensor_type == 1`, иначе `мм`
6. Итерирует по `valid_ops` — операциям, у которых задано `p_switch_dur`. Для каждой операции:
   - Выводит общие параметры: время коммутации, разновременность, полный ход, перелёт, отскок, ход после размыкания, среднюю скорость
   - Если в операции есть данные по полюсам (`poles`), строит выровненную таблицу по фазам A/B/C через вспомогательную вложенную функцию `_row(label, key, fmt_fn)`
7. Добавляет блок «СЛУЖЕБНАЯ ИНФОРМАЦИЯ» (размеры файлов, CRC, счётчики DAQ)
8. Возвращает весь список строк через `"\n".join(lines)`

**Связи:** вызывается из `ComtradeViewer._load_info_file()` при обнаружении ключей `meas_sett` или `calc_data` в JSON.

***

### `convert_drm_json_to_report(data, source_path) → str`

Аналогична предыдущей, но для формата DRM (Dynamic Resistance Measurement — динамическое сопротивление контактов).

**Аргументы:**
- `data: dict` — содержимое JSON DRM-файла
- `source_path: str` — путь к исходному файлу

**Внутренняя логика:**
1. Извлекает секции `microohm_settings`, `microohm_results`, `calibrations`
2. Использует локальные словари `MODE_MAP`, `TRIGGER_MAP`, `SENSOR_MAP` для расшифровки режимов
3. Строит блоки «НАСТРОЙКИ МИКРООММЕТРА» (режим, ток, период, канал, триггер, зажимы) и «РЕЗУЛЬТАТЫ ИЗМЕРЕНИЯ» (сопротивление в мОм, напряжение, ток)
4. Если присутствуют калибровочные коэффициенты `a`, `b`, `skew` — строит таблицу по 5 каналам (Ток, Напряжение, Доп.1, Доп.2, Угол) с форматами `2e`/`.4f`
5. Добавляет служебный блок с частотой дискретизации, количеством отсчётов и размерами файлов

**Связи:** вызывается из `ComtradeViewer._load_info_file()` при обнаружении ключей `type == "drm"`, `microohm_settings` или `microohm_results`.

## Класс `CurveRef` (dataclass)

Описание одной построенной кривой. Хранит всё необходимое для привязки курсоров и расчётов по участку.

| Поле | Тип | Описание |
|---|---|---|
| `uid` | `str` | Уникальный идентификатор в форме `"channel_type:index"` (например `"analog:0"`) |
| `ax` | `Axes` | Matplotlib-ось, на которой нарисована кривая |
| `line` | `Line2D` | Объект линии Matplotlib |
| `channel_type` | `str` | `"analog"` или `"status"` |
| `channel_index` | `int` | Индекс канала в COMTRADE |
| `label` | `str` | Имя канала из CFG |
| `time_ms` | `np.ndarray` | Временная ось в миллисекундах |
| `values` | `np.ndarray` | Массив значений канала |

`CurveRef` является центральным объектом связи между графиком и курсорами: `CursorState` хранит ссылку на него, а `_calculate_segment_stats` работает непосредственно с его массивами `time_ms` и `values`.

***

## Класс `CursorState` (dataclass)

Состояние одного измерительного курсора. Курсор привязывается не к экранным координатам, а к конкретному индексу сэмпла (`sample_index`) в конкретной кривой, что гарантирует вычисление точных значений из реальных данных COMTRADE.

| Поле | Тип | Описание |
|---|---|---|
| `name` | `str` | Отображаемое имя курсора (`"Курсор 1"`, `"Курсор 2"`) |
| `color` | `str` | Цвет маркера и линии (`"red"`, `"blue"`) |
| `ax` | `Optional[Axes]` | Ось привязки курсора |
| `curve` | `Optional[CurveRef]` | Привязанная кривая |
| `sample_index` | `Optional[int]` | Индекс ближайшего сэмпла к точке клика |
| `x_ms` | `Optional[float]` | Временная координата в мс |
| `y_value` | `Optional[float]` | Значение сигнала в точке |
| `artists` | `list[Artist]` | Список графических объектов (линии, маркеры, аннотации) |

### Методы `CursorState`

#### `clear() → None`
Полный сброс курсора: обнуляет все поля состояния и удаляет все графические объекты через `remove_artists()`.

#### `remove_artists() → None`
Итерирует по списку `self.artists` и вызывает `artist.remove()` для каждого. Ошибки удаления игнорируются (объект мог быть уже удалён при очистке Figure). После удаления список очищается через `self.artists.clear()`.

#### `is_set` (property) → bool
Возвращает `True` только если все четыре ключевых поля одновременно заданы: `ax`, `curve`, `sample_index`, `x_ms`, `y_value`. Используется как защита перед любым расчётом или отрисовкой.

## Класс `ComtradePlotCanvas`

**Базовый класс:** `FigureCanvasQTAgg` (Matplotlib)

Matplotlib-холст, встроенный в PyQt6. Инициализирует `Figure` размером 12×7 дюймов при 100 DPI с включённым `constrained_layout` (автоматическое распределение подграфиков без перекрытия).

### `__init__(parent)`
- Создаёт `self.fig = Figure(figsize=(12, 7), dpi=100, constrained_layout=True)`
- Вызывает `super().__init__(self.fig)` для связки с Qt-виджетом
- Устанавливает `ClickFocus` — холст получает фокус при щелчке мышью
- Задаёт политику размера `Expanding` по обоим измерениям (растягивается вместе с окном)

`ComtradePlotCanvas` не содержит бизнес-логики и выступает исключительно как хост для Figure. Все операции с осями выполняются в `ComtradeViewer`.

## Класс `ComtradeViewer`

**Базовый класс:** `QMainWindow`

Главный и единственный «монолитный» класс приложения. Объединяет загрузку файла, построение графиков, управление курсорами и экспорт.

### Атрибут `TRANSLATIONS`

Словарь двух локализаций — `"ru"` и `"en"`. Каждая локализация содержит строки интерфейса, включая вложенный словарь `"info_keys"` для перевода ключей .info-файлов. Метод `tr(key, **kwargs)` производит подстановку по этому словарю с опциональным форматированием аргументов.

### Атрибуты экземпляра (инициализируются в `__init__`)

| Атрибут | Тип | Описание |
|---|---|---|
| `language` | `str` | Текущий язык интерфейса (`"ru"`) |
| `comtrade_file` | `Optional[Comtrade]` | Загруженный COMTRADE-объект |
| `current_cfg_path` | `Optional[Path]` | Путь к открытому CFG-файлу |
| `current_info_path` | `Optional[Path]` | Путь к связанному .info-файлу |
| `plot_mode` | `str` | Текущий режим построения: `"overlay"` или `"parallel"` |
| `curves` | `list[CurveRef]` | Список всех построенных кривых |
| `annotation_artists` | `list[Artist]` | Аннотации на графике (блок с параметрами участка) |
| `cursor1` | `CursorState` | Первый курсор (ЛКМ, красный) |
| `cursor2` | `CursorState` | Второй курсор (ПКМ, синий) |
| `_last_selected_channels` | `list[tuple[str, int]]` | Выбранные каналы предыдущего сеанса (для восстановления) |

## Методы `ComtradeViewer`

### Инициализация и UI

#### `__init__() → None`
Точка создания объекта. Последовательно:
1. Устанавливает заголовок окна и размер 1750×980 пикселей
2. Инициализирует атрибуты состояния
3. Вызывает `_init_ui()` — строит весь интерфейс
4. Вызывает `_connect_canvas_events()` — подключает обработчик мыши
5. Вызывает `_update_measurement_info()` — очищает панель измерений
6. Вызывает `clear_plot(keep_message=True)` — показывает пустой холст с подсказкой

#### `_init_ui() → None`
Строит весь пользовательский интерфейс. Компоновка реализована через два вложенных `QSplitter`:

- **`main_splitter`** (горизонтальный): делит окно на левую панель управления (480 пикселей) и правую область графика (1220 пикселей). Правая сторона растягивается при изменении размера окна.
- **`left_splitter`** (вертикальный): делит левую панель на верхний блок управления (620 пикселей) и нижний блок с результатами измерений (300 пикселей).

Верхний блок управления содержит следующие виджеты (сверху вниз):
- `open_btn` — кнопка открытия CFG-файла
- `info_label` — метка с краткой сводкой по загруженному файлу
- `mode_combo` — ComboBox выбора режима просмотра (наложение/параллельный), по умолчанию параллельный
- `channel_list` — многострочный список каналов с поддержкой множественного выбора
- `plot_btn` / `plot_all_btn` — кнопки построения выбранных и всех аналоговых каналов
- `measure_mode_combo` — ComboBox режима измерения (авто / только одна кривая)
- `measure_curve_combo` — ComboBox выбора конкретной кривой для режима «одна кривая»
- `export_csv_btn` / `clear_cursor_btn` — кнопки экспорта и сброса курсоров

Нижний блок содержит `QTabWidget` с двумя вкладками:
- **«Измерения»** — `cursor_info` (QTextEdit, read-only) с текстовым отчётом курсоров
- **«Результаты»** / **«INFO»** — `info_text` (QTextEdit, read-only) с протоколом из .info файла и кнопкой `save_info_btn`

Правая панель содержит `NavigationToolbar2QT` (стандартная панель Matplotlib) и `ComtradePlotCanvas`.

#### `_connect_canvas_events() → None`
Подключает единственный обработчик: `self.canvas.mpl_connect("button_press_event", self.on_canvas_click)`. Все клики по графику обрабатываются в `on_canvas_click`.

### Вспомогательные методы (адаптер к библиотеке comtrade)

Эта группа методов изолирует всю остальную логику приложения от различий в именовании атрибутов между версиями библиотеки `comtrade`.

#### `_get_attr(*names, default) → Any`
Перебирает список имён атрибутов и возвращает значение первого найденного у `self.comtrade_file`. Если файл не загружен или ни одно имя не найдено — возвращает `default`. Это базовый метод безопасного доступа ко всем данным COMTRADE.

#### `tr(key, **kwargs) → str`
Метод локализации. Ищет ключ `key` в `TRANSLATIONS[self.language]`. При передаче kwargs — форматирует строку через `.format(**kwargs)`. Если ключ не найден — возвращает сам ключ.

#### Группа аксессоров к данным COMTRADE

| Метод | Возвращает |
|---|---|
| `_analog_count()` | Количество аналоговых каналов |
| `_status_count()` | Количество дискретных каналов |
| `_names_analog()` | Список имён аналоговых каналов |
| `_names_status()` | Список имён дискретных каналов |
| `_station_name()` | Имя подстанции из CFG |
| `_device_name()` | Идентификатор устройства записи |
| `_frequency()` | Номинальная частота |
| `_time_seconds()` | Временная ось в секундах (numpy array) |
| `_time_ms()` | Временная ось в миллисекундах (`_time_seconds() * 1000`) |
| `_analog_values(index)` | Значения аналогового канала по индексу |
| `_status_values(index)` | Значения дискретного канала по индексу |
| `_channel_name(type, index)` | Имя канала по типу и индексу |
| `_channel_values(type, index)` | Значения канала (аналог/дискрет) |

#### `_channel_unit(channel_type, channel_index) → str`
Определяет физическую единицу аналогового канала. Алгоритм поиска:
1. Пробует получить единицу через объект `cfg.analog_channels[index].uu`
2. Если не вышло — читает строку из текста CFG-файла напрямую: строка с индексом `2 + channel_index`, поле с индексом 4 (разделитель `,`)

#### `_detect_unit_type(channel_type, channel_index) → str`
Классифицирует единицу канала в одну из трёх категорий: `"mm"` (линейный ход), `"angle"` (угловой), `"unknown"`. Использует как единицу из CFG, так и имя канала (ищет ключевые слова `"мм"`, `"ход"`, `"travel"`, `"stroke"`, `"deg"`, `"угол"` и т.д.).

#### `_get_segment_units() → tuple[str, str]`
Возвращает пару `(val_unit, speed_unit)` для отображения параметров участка. Единицы определяются по первому курсору: `("мм", "м/с")` для линейного, `("°", "°/с")` для углового, `("", "м/с")` по умолчанию.

#### `_speed_value_for_display(stats) → float`
Выбирает подходящее значение скорости из словаря `stats`: для линейных датчиков берёт `avg_rate_per_ms` (конвертируется в м/с), для угловых — `avg_rate_per_s`.

### Загрузка файла

Цепочка загрузки файла: `open_file()` → `_load_comtrade_with_fallback()` → `_prepare_fixed_cfg_file()` → `_fix_cfg_text()` / `_read_text_with_fallback()` / `_detect_last_sample_from_dat()`

#### `_read_text_with_fallback(file_path) → tuple[str, str]`
Последовательно пробует прочитать файл в кодировках: `cp1251`, `utf-8-sig`, `utf-8`, `cp866`, `windows-1251`, `latin-1`. Возвращает текст и успешную кодировку. При полном провале — выбрасывает `RuntimeError` с перечнем ошибок.

#### `_normalize_cfg_date(date_str) → str`
Нормализует строку даты из CFG-файла к формату `DD/MM/YYYY`. Поддерживает форматы `YYYY/MM/DD`, `YYYY-MM-DD`, `YYYYMMDD`. Если формат не распознан — возвращает строку без изменений.

#### `_normalize_cfg_timestamp_line(line) → str`
Применяет `_normalize_cfg_date` к первой части строки временной метки CFG (формат: `дата,время,наносекунды`).

#### `_detect_last_sample_from_dat(dat_file) → int`
Читает DAT-файл построчно и извлекает номер последнего непустого отсчёта из первого поля последней строки. Этот номер нужен для исправления блока частоты дискретизации в CFG.

#### `_fix_cfg_text(text, last_sample) → str`
Исправляет две распространённых проблемы в CFG-файлах:
1. **Нестандартные форматы дат** — заменяет все строки с датой в формате `YYYY/MM/DD`, `YYYY-MM-DD` или `YYYYMMDD` на корректный `DD/MM/YYYY`
2. **Неверный счётчик последнего отсчёта** — вычисляет позицию блока частоты дискретизации (строка `idx_rates_start` после строки с количеством частот) и заменяет число отсчётов на `last_sample` из DAT

#### `_prepare_fixed_cfg_file(cfg_file, dat_file) → tuple[str, str, int]`
Координирует создание исправленного CFG:
1. Читает оригинальный CFG через `_read_text_with_fallback`
2. Определяет номер последнего отсчёта через `_detect_last_sample_from_dat`
3. Применяет `_fix_cfg_text`
4. Записывает исправленный текст во временный файл через `tempfile.NamedTemporaryFile` с той же кодировкой
5. Возвращает путь к временному файлу, кодировку, номер последнего отсчёта

#### `_load_comtrade_with_fallback(cfg_file, dat_file) → tuple[Comtrade, str, int]`
Получает исправленный CFG через `_prepare_fixed_cfg_file`. Затем перебирает список кодировок и пробует `Comtrade().load(fixed_cfg, dat_file, encoding=enc)`. Возвращает первый успешный результат. При полном провале выбрасывает `RuntimeError` с журналом ошибок.

#### `open_file() → None`
Обработчик кнопки «Открыть CFG». Полный сценарий:
1. Открывает диалог выбора файла (фильтр `.cfg`)
2. Проверяет существование соответствующего `.dat` файла
3. Сохраняет текущий выбор каналов в `_last_selected_channels`
4. Загружает файл через `_load_comtrade_with_fallback`
5. Проверяет, что `len(time) > 0` (файл не пустой)
6. Обновляет `comtrade_file`, `current_cfg_path`
7. Загружает .info файл через `_load_info_file`
8. Обновляет `info_label` (метаданные) и `channel_list`
9. Очищает график
10. Восстанавливает предыдущий выбор каналов через `_try_restore_and_plot`
11. Показывает статус в строке состояния

***

### Работа с .info файлом

#### `_base_record_name(path) → str`
Извлекает базовое имя файла без числового суффикса. Например, `"record-2"` → `"record"`. Используется для поиска связанного .info файла.

#### `_find_related_info_file(cfg_path) → Optional[Path]`
Ищет .info файл рядом с CFG:
1. Сначала проверяет файл с тем же именем и расширением `.info`
2. Затем ищет любые файлы по шаблону `{base_name}*.info` в той же директории
3. Дедублирует результаты через `set` resolved-путей
4. Возвращает первый найденный или `None`

#### `_localize_info_key(key) → str`
Нормализует ключ (убирает кавычки, лишние пробелы, заменяет типографские кавычки на ASCII) и ищет его в словаре `info_keys` текущей локализации. Возвращает перевод или исходный ключ.

#### `_localize_info_text(text) → str`
Применяет `_localize_info_key` к левой части каждой строки текста .info (разделители `:`, `=`, ` - `). Используется для «сырых» текстовых .info файлов (не JSON).

#### `_load_info_file(cfg_path) → None`
Основной метод загрузки и отображения .info:
1. Ищет связанный .info через `_find_related_info_file`
2. Читает его через `_read_text_with_fallback`
3. Пробует разобрать как JSON:
   - Если есть ключи `meas_sett` / `calc_data` → вызывает `convert_info_json_to_report`
   - Если тип `"drm"` или есть `microohm_settings` / `microohm_results` → вызывает `convert_drm_json_to_report`
4. Если JSON не распознан → применяет `_localize_info_text` к исходному тексту
5. Результат помещает в `self.info_text`

### Восстановление состояния

#### `_restore_channel_selection(channels) → None`
Проходит по всем элементам `channel_list` и выделяет те, чьи данные (`UserRole`) находятся в переданном наборе. Позволяет восстановить выделение каналов после перезагрузки файла.

#### `_try_restore_and_plot() → None`
При наличии сохранённого выбора каналов (`_last_selected_channels`) — восстанавливает выделение через `_restore_channel_selection` и немедленно строит график. Это обеспечивает бесшовное переключение между файлами одной серии измерений.

### Режим отображения

#### `on_mode_changed() → None`
Считывает `currentData()` из `mode_combo` (`"overlay"` или `"parallel"`) и обновляет `self.plot_mode`.

### Построение графиков

#### `clear_plot(keep_message) → None`
Полная очистка состояния графика:
1. `self.canvas.fig.clear()` — удаляет все оси
2. `self.curves.clear()` — очищает список кривых
3. `_clear_annotation_artists()` — удаляет аннотации участка
4. `clear_cursors(redraw=False)` — сбрасывает курсоры без перерисовки
5. `_refresh_measurement_curve_combo()` — обновляет выпадающий список кривых
6. Добавляет пустую ось с заголовком «Загрузите файл и выберите каналы»

#### `plot_selected_channels() → None`
Обработчик кнопки «Отобразить выбранные». Получает список выбранных элементов из `channel_list`, извлекает из них `UserRole` (пары `(type, index)`) и направляет в `_plot_overlay` или `_plot_parallel` в зависимости от `plot_mode`. После построения обновляет комбо кривых и перерисовывает курсоры.

#### `plot_all_analog() → None`
Удобная кнопка для быстрого просмотра: формирует список `[("analog", i) for i in range(N)]` и передаёт его прямо в `_plot_parallel`, минуя `channel_list`. Всегда использует параллельный режим независимо от текущего `plot_mode`.

#### `_plot_overlay(items) → None`
Режим наложения: строит все каналы на **одной** общей оси (`add_subplot(111)`).
- Очищает Figure и список `curves`
- Перебирает `items`: для каждого канала строит линию с цветом из циклического пула `tab:blue`, `tab:red`, `tab:green`, …
- Создаёт объект `CurveRef` и добавляет в `self.curves`
- Добавляет легенду

#### `_plot_parallel(items, title) → None`
Режим параллельного просмотра: для каждого канала создаёт **отдельную подось** (`add_subplot(N, 1, row)`).
- Все оси связываются общей осью X через `sharex=shared_ax` (первая ось передаётся как shared)
- Метка Y содержит имя канала и физическую единицу из CFG
- Аналоговые каналы — синие, дискретные — красные
- Подпись оси X отображается только на нижней оси

#### `_refresh_measurement_curve_combo() → None`
Обновляет `measure_curve_combo` после каждого построения. Сохраняет UID ранее выбранной кривой и пытается восстановить выбор после пересборки списка.

#### `_curve_by_uid(uid) → Optional[CurveRef]`
Линейный поиск `CurveRef` по `uid` в списке `self.curves`.

#### `_selected_measurement_curve() → Optional[CurveRef]`
Возвращает объект `CurveRef`, выбранный в `measure_curve_combo`.

### Логика курсоров

Вся работа с курсорами строится вокруг трёх операций: установка, удаление, перерисовка.

#### `on_canvas_click(event) → None`
Центральный обработчик кликов по холсту. Алгоритм:
1. Проверяет предусловия: файл загружен, клик внутри оси (`event.inaxes`), кнопка 1 или 3, панель Matplotlib не активна (иначе клик принадлежит инструменту масштабирования)
2. Выбирает целевой курсор: ЛКМ → `cursor1`, ПКМ → `cursor2`
3. Проверяет через `_click_near_cursor_line`, не попал ли клик на линию уже установленного курсора — если да, **удаляет** курсор
4. Иначе — вызывает `_pick_curve_and_index` для определения кривой и сэмпла, затем `_set_cursor` для установки
5. В любом случае завершается `_redraw_cursors()`, `_update_measurement_info()`, `canvas.draw_idle()`

#### `_set_cursor(cursor, curve, sample_index) → None`
Заполняет все поля `CursorState`: ось, кривую, индекс сэмпла, координаты `x_ms` и `y_value`. Все значения берутся из массивов `CurveRef` по индексу.

#### `_pick_curve_and_index(event) → tuple[CurveRef|None, int|None]`
Определяет, к какой кривой относится клик:
- В режиме `"single"` — проверяет только кривую из `measure_curve_combo`, если ось совпадает с кликнутой
- В режиме `"auto"` — ищет кривые на кликнутой оси; если не нашёл — ищет среди всех. Для каждого кандидата находит ближайший сэмпл через `np.argmin(|time_ms - x_click|)` и выбирает кривую с минимальным расстоянием по оси X

#### `_click_near_cursor_line(event, cursor, threshold_px) → bool`
Проверяет, находится ли клик в пределах `threshold_px` (по умолчанию 8 пикселей) от вертикальной линии курсора. Преобразует временную координату курсора в экранные пиксели через `ax.transData.transform()` и сравнивает с `event.x`.

#### `_redraw_cursors() → None`
Полная перерисовка всех визуальных элементов курсоров:
1. Удаляет старые artists через `cursor.remove_artists()` и `_clear_annotation_artists()`
2. Для каждого установленного курсора:
   - Рисует вертикальную штриховую линию через `ax.axvline` **на всех осях** Figure (для синхронного отображения на параллельных подграфиках)
   - Рисует маркер `"o"` и текстовую аннотацию **только на оси привязки**
3. Если оба курсора установлены на одной кривой — вызывает `_build_segment_annotation()` и добавляет блок параметров участка как `ax.text` в координатах осей (0.015, 0.985)

#### `clear_cursors(redraw) → None`
Сбрасывает оба курсора и аннотации. Параметр `redraw=False` позволяет вызывать во время пересборки Figure без лишней перерисовки.

#### `_clear_annotation_artists() → None`
Удаляет только аннотации участка (список `annotation_artists`), не трогая курсорные artists.

***

### Расчёт параметров участка

#### `_calculate_segment_stats() → Optional[dict]`
Главный вычислительный метод. Расчёт возможен только если оба курсора установлены на **одной и той же** кривой (`cursor1.curve is cursor2.curve`).

Алгоритм:
1. Определяет индексы `i1`, `i2` и диапазон `lo, hi = sorted((i1, i2))`
2. Вычисляет `delta_t_ms = x2 - x1`, `delta_y = y2 - y1`
3. Извлекает подмассивы `t_seg_ms` и `y_seg` для участка `[lo:hi+1]`
4. Вычисляет локальные производные как `dy / dt_ms` (исключая нулевые интервалы)
5. Находит пару соседних сэмплов с максимальной абсолютной скоростью (`max_pair`)

Возвращаемый словарь `stats` содержит:

| Ключ | Описание |
|---|---|
| `delta_t_ms` | Длительность участка, мс |
| `delta_y` | Изменение значения |
| `avg_rate_per_ms` | Средняя скорость (ΔY/ΔT в 1/мс) |
| `avg_rate_per_s` | Средняя скорость (ΔY/ΔT в 1/с) |
| `y_min`, `y_max` | Экстремумы на участке |
| `samples` | Количество отсчётов |
| `local_rate_*` | Статистика локальных производных |
| `max_pair` | Словарь с параметрами пары сэмплов максимальной скорости |
| `segment_time_ms` | Временная ось участка |
| `segment_values` | Значения на участке |

#### `_build_segment_annotation() → str`
Формирует компактную трёхстрочную аннотацию из `_calculate_segment_stats`: `DT`, `DY`, `Vsr` с соответствующими единицами.

***

### Панель измерений

#### `_cursor_block(cursor, icon) → str`
Формирует текстовый блок для одного курсора: иконка, имя, канал, время в мс, значение. При незаданном курсоре — строка «не установлен».

#### `_update_measurement_info() → None`
Собирает полный текстовый отчёт для `cursor_info` из блоков:
1. Заголовок «ИЗМЕРЕНИЯ КУРСОРОВ»
2. Блок курсора 1 (`_cursor_block`)
3. Блок курсора 2
4. Блок режима привязки (авто/одна кривая, выбранная кривая)
5. Блок параметров участка (если оба курсора на одной кривой) или сообщение о несовпадении

Вызывается при каждом изменении состояния курсоров.

***

### Экспорт

#### `export_measurements_csv() → None`
Экспортирует все результаты измерений в CSV-файл (кодировка `cp1251`, разделитель `;` для совместимости с Excel).

Структура CSV — три колонки: `section`, `key`, `value`. Секции:
- `file` — имя CFG, устройство
- `курсор_1` / `курсор_2` — `is_set`, `curve_label`, `sample_index`, `time_ms`, `value`
- `segment` — единицы (`val_unit`, `speed_unit`), параметры участка (`delta_t_ms`, `delta_y`, средняя скорость, `y_min`, `y_max`)

Имя файла по умолчанию: `{stem}_measurements.csv` рядом с домашней директорией.

#### `save_info_report() → None`
Сохраняет текущее содержимое вкладки «Результаты» (`info_text`) в текстовый `.txt` файл с кодировкой `utf-8`. Имя файла по умолчанию: `{info_stem}_report.txt` или `{cfg_stem}_report.txt`. Перед сохранением проверяет, что текст не является одним из служебных сообщений об ошибке.

## Замечания по отказоустойчивости

Весь код загрузки оборачивается в `try/except` на нескольких уровнях. Ключевые механизмы защиты:

- **Кодировки:** перебор 6 кодировок при чтении текстовых файлов
- **Форматы дат CFG:** нормализация трёх нестандартных форматов в корректный `DD/MM/YYYY`
- **Счётчик отсчётов:** автоматическое исправление по последней строке DAT
- **Атрибуты comtrade:** `_get_attr` пробует несколько имён атрибутов (для разных версий библиотеки)
- **Курсоры:** `is_set` property как шлюз перед каждой операцией; удаление artists с поглощением исключений
- **Клики мышью:** проверка `toolbar.mode` блокирует курсоры при активном инструменте масштабирования/панорамирования
